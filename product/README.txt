SELLERPHOTO STUDIO — FULL OFFLINE EDITION
=========================================

QUICK START
1. Extract the ZIP file to a folder.
2. Double-click index.html.
3. Add JPG, PNG, or WebP product photos.
4. Choose a marketplace, quick-commerce, D2C, or social preset.
5. Add an optional SKU prefix and branding.
6. Click Download ZIP.

The ZIP contains the finished images and, when selected, a catalogue manifest CSV mapping source files to exported filenames. Nothing is uploaded; image processing happens entirely in your browser.

SUPPORTED BROWSERS
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

TIPS
- Start with clear, well-lit product photos.
- Use Fit to keep the entire product visible.
- Use Fill when the original image already has comfortable space around it.
- Use a short, stable SKU prefix such as BRAND-CATEGORY-001.
- JPG at 85–92% is a strong balance between quality and file size.
- PNG is best for graphics, logos, and screenshots.
- Check the current image rules in each seller portal before uploading.

LIMITS
- Up to 50 photos per batch.
- Individual source files must be 25 MB or smaller.
- This edition standardises the canvas; it does not remove backgrounds with AI.
